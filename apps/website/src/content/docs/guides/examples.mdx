Example games live in the [`examples/`](https://github.com/mamello-justice/TooDeeEngine/tree/main/examples)
directory of the repository. Each one has its own README with features, controls, and learning objectives.

## Building Examples

Examples are disabled by default. Set `TOO_DEE_ENGINE_BUILD_EXAMPLES=true` in your `.env` file, then:

```bash
just setup
just build
```

## Running Examples

```bash
just example hello_world
just example moving_shapes
```
